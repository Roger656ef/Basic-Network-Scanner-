## About

Python Network Scanner is a lightweight network scanning project developed using Python.

The project aims to explore basic network scanning concepts and understand how network discovery and port scanning work.

## Features

- Python-based implementation
- Network scanning functionality
- Lightweight design
- Command-line interface

## Technologies Used

- Python
- Socket Programming

## Installation

Clone the repository:

```bash
git clone https://github.com/Roger656ef/Python-Network-Scanner.git
```

Open the project directory:

```bash
cd Python-Network-Scanner
```

Run:

```bash
python main.py
```

## Usage

Use the scanner only on networks and systems you own or have explicit permission to assess.
